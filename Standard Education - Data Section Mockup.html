Note 2 — the regional layer is the point. Each state names its intermediate agency differently (Georgia: RESA; Kansas: education service center; elsewhere: ESC, BOCES, IU, AEA). The nav should use the state’s own vocabulary at that level rather than forcing one label — the label is a per-state field, not a hard-coded word.

How the snapshots are built

01

Public data, assembled

State report cards, enrollment files and federal collections, normalized into one comparable shape.
02

Regional context added

Every district is shown against its RESA or service-center peers, not just the state average.
03

Refreshed each cycle

Updated when the state publishes, with the source and vintage noted on every page.
